# PokéSurvivor troubleshooting

[Back to the game overview](../README.md) · [Play PokéSurvivor](https://survivorpoke.com/)

Find the symptom below and work through its checks in order. Before refreshing or clearing site storage, inspect **Settings → Account**: refreshing ends the active battle, and clearing an unbound anonymous session can remove access to its progress.

## The game does not load or stays on an empty screen

1. Confirm you opened [survivorpoke.com](https://survivorpoke.com/) and have a working internet connection.
2. Allow JavaScript and the game's resources to load. Check whether a browser content blocker is blocking the site.
3. If you opened the game inside a small browser panel, try [the dedicated game address](https://survivorpoke.com/play/) in a normal browser tab.
4. If the scene appears but account sync fails, read the save status. Drawing the game and connecting to account services are different steps.
5. If a reload is needed, keep the existing browser profile and storage. Do not delete the saved session merely to retry loading.

If it still fails, report the device, browser/version, visible message and whether the root or dedicated game address behaved differently.

## Movement or attack buttons do nothing

Finish any open reward, item or Bond choice first. Click/tap the game to restore focus after visiting another tab. Release and press movement keys again; on touch, lift your finger and begin a fresh drag outside the HUD.

Check the highlighted attack icon. Only the active ordinary slot attacks. A buff move can be working while causing no direct damage. If switching slots is blocked, check for **Choice Band**, which prevents ordinary move switching. In a level-up screen, **1–3** selects reward cards; during battle, **1–4** selects move slots.

If effects and input are both slow, choose **Settings → Graphics → Low** or Auto. See [controls and mobile](controls-and-mobile.md) for the complete inputs.

## Mobile stays in portrait, feels cramped or runs slowly

Turn the device to landscape and disable rotation lock. Open the dedicated game tab if its surrounding panel leaves too little space. Use the floating joystick by dragging from an open part of the battlefield.

Try Auto/Low graphics and **Less shakes and flashes**. Joystick size changes drag distance, not movement speed. Fullscreen support varies by browser; on iPhone/iPad, Safari's **Share → Add to Home Screen** offers a separate game window. A shortcut is not a save backup, and its session may differ from a regular tab. Read the [mobile guide](https://survivorpoke.com/guides/mobile/) before changing contexts.

## A move will not evolve

Check its row in [all 59 recipes](move-evolutions.md). It needs **level 5**, the exact required **current-run card**, and selection of the **gold evolution reward**. Permanent shop upgrades, natural stats and held items do not count as that card.

For example, Ember needs Power; Bubble needs Sprint. Petal Blizzard needs Synthesis, while Razor Leaf needs Reflexes. A move absent from the table has no listed recipe, and an evolved move does not receive a second evolution through this system.

## No legendary rift appeared

Rifts first become eligible after **75 seconds**; eligible checks occur every **30 seconds**. A live ordinary boss blocks the opening attempt, and an existing portal/arena or unsuitable map space can postpone it. No new rifts open from minute **28**.

Clear the boss and survive until the next eligible check. Watch for the portal indicator: an open portal expires after **45 seconds**. Refreshing does not force a portal and ends the current battle. See [rift conditions](https://survivorpoke.com/guides/legendary-rifts/).

## Progress is missing or cloud sync is pending

Return to the same browser, profile and account nickname. This game's accounts are separate from those at pokesurvivor.com. A new anonymous nickname can mean you opened a different session.

Keep pending changes in the original browser and restore its connection. Cloud writes have a minimum spacing of about **65 seconds**; wait for the visible synced status rather than assuming a local save has uploaded. If already linked, explicitly sign into the existing Google account. A public nickname alone cannot recover an unbound anonymous save. Follow [save and sync](save-and-sync.md) before removing any storage.

## A leaderboard result is missing

Confirm the run lasted at least **60 seconds** and finished through normal game controls. An unfinished battle reloaded midway is not a completed submission. Allow the upload to finish before refreshing.

Check Solo/Group, period, Friends/All and any Pokémon filter. A shorter result does not replace a better existing one. Daily, weekly and monthly boards show **top 50**; try **All-time** for a broader exact rank. Period boundaries use **Europe/Madrid** time, and browser leaderboard reads can be cached for **30 minutes**. See [leaderboard rules](https://survivorpoke.com/guides/leaderboard/) for these distinctions.

## Co-op stays Connecting or will not start

Check accepted friend/room invitations, then return everyone to the lobby and keep tabs visible. The host cannot start while a required member is connecting or failed. Try another Wi-Fi or mobile-data network if negotiation fails. TURN relay access is still being configured, so some restrictive network pairs cannot connect. Follow [the co-op checklist](multiplayer.md); deleting an account does not fix a peer connection.

## Report a problem without exposing your account

Include the affected guide/game screen, device and browser/version, what you did, the expected result and the actual message. A screenshot of the symptom helps. Remove private account details before sharing it; never post passwords, sign-in tokens or private Google credentials.
